1. goodnight000/api-anything — Turns any website without a public API into a callable HTTP API for AI agents

github.com/goodnight000/api-anything · ⭐ 2,963 total (+0 this week) · 📈 ~478/7d · Language: TypeScript · Source: search/fresh-rising · 🆕 new this week

What it is: Turns any website without a public API into a callable HTTP API for AI agents. It learns a site's own frontend requests once, shares that knowledge via a community catalog, and self-heals when sites change.

Why it matters (SR/EU): For Eastern EU engineering shops it's a direct cost play: replacing browser-automation agent stacks with plain HTTP cuts token and compute costs massively, and the shared-catalog model is an open infrastructure niche Western vendors (Browserbase, Firecrawl) only partially cover.

README highlights (translated):

  • Learns the underlying HTTP requests a site's own pages make, then exposes them as plain HTTP calls instead of expensive browser automation
  • Ships as an MCP server/skill for Claude Code, Cursor, Codex, Gemini CLI and others; setup via a single npx command, no account or API key
  • Shared catalog of learned APIs with cookies and tokens stripped, so every agent benefits from what one agent learned
  • Benchmarks: 1.5-2x faster and roughly half the tokens vs. headless-Chrome agents on Goodreads, Google Flights, Netflix, IKEA tasks
  • Structured failure output (class/reason/next) and privacy controls (--local-only keeps everything on-machine)
  • ~3k stars in about a week of existence, MIT licensed, TypeScript/Node >= 22.13, published on npm
